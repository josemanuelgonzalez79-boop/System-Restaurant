02 · Conservar

Guardar fuera del servidor

Copia el ZIP a una unidad externa o ubicación segura distinta del equipo de Essential. El archivo contiene ventas, usuarios y contraseñas cifradas: no lo compartas por mensajería.

Genera una copia al menos al cierre de cada jornada y comprueba una restauración periódicamente.

03 · Recuperar

Restauración guiada en el servidor

En Windows, ejecuta SystemRestaurantBack\scripts\Restaurar-Essential.ps1 con el ZIP descargado. Primero crea una base de prueba nueva, verifica SHA-256 y Flyway y conserva intacta la base actual. Después de detener Spring Boot, puedes promover esa copia con -Promover; antes guarda otra copia de seguridad y conserva la base anterior. 

powershell -ExecutionPolicy Bypass -File .\scripts\Restaurar-Essential.ps1 -Archivo "C:\Respaldos\Essential-AAAAMMDD-HHMMSS.zip" -PgBin "C:\Program Files\PostgreSQL\18\bin"

Nunca restaures desde una tablet. La restauración debe realizarla el responsable del servidor fuera del horario de servicio.
